DocAgent: Study Assistant for Lecture Slides

RAG
Python · LangChain · Chroma · Sentence-Transformers · PyMuPDF · Groq

A retrieval-augmented study assistant for my Master's lecture slides. Ask a question, it finds the most relevant slides and an LLM answers using only those slides, citing the file and slide number for every source.

how it works: ingest → embed → retrieve → answer with citations
1,874slide chunks
75%hit@6
90%hit@10
0.524MRR
  • Built an ingestion pipeline over 57 lecture PDFs (2,678 slides) from two courses: one chunk per slide, with repeated headers, near-empty slides and 569 duplicate recap slides removed.
  • Chose slide-level chunking over fixed-size chunks: each slide is already one topic, and it gives exact, checkable citations.
  • Wrote a retrieval evaluation on 20 hand-labelled questions (hit@k, MRR). Deduplication raised hit@6 from 70% to 75% and gave the LLM 6 distinct slides instead of 5.
  • Documented the limits honestly: formulas are lost in PDF text extraction, and a reranker plus claim-level citation checks are the next steps.

Reinforcement Learning Training Pipeline for Autonomous Inspection

Python · Pygame · Q-learning · Deep Q-Network

A custom grid-based simulation environment for autonomous safety-inspection tasks, where I trained agents to navigate it both efficiently and safely.

how it works: agent acts → environment rewards → agent learns, tracked per run
  • Built the environment from scratch, then trained Q-learning and DQN agents with experience replay, reward shaping, and epsilon-greedy decay.
  • Set up a reproducible training pipeline with fixed seeds and structured configs, so I could compare different agent variants fairly.
  • Tracked convergence, success rate, and episode length along the way, and used that to guide hyperparameter tuning and iron out instability.
